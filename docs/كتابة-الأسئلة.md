# تعليمات كتابة أسئلة للعبة «انت صح»

انسخ هذا الملف كامل وأعطه للمساعد، ثم قل له أي فئة تبي.

---

## ما هي اللعبة

لعبة أسئلة جماعية بالعربي، فريقان يتنافسان على لوحة فيها ٦ فئات.
كل فئة فيها ٦ مربعات: **٢٠٠ · ٢٠٠ · ٤٠٠ · ٤٠٠ · ٦٠٠ · ٦٠٠**.
الفريق يختار مربعاً، يُقرأ السؤال، ويجاوب. الإجابة الصحيحة تعطيه نقاط المربع.

الجمهور: شباب خليجيون في ديوانية. اللغة عربية واضحة وبسيطة.

---

## درجات الصعوبة

| النقاط | المستوى |
|---|---|
| **٢٠٠** | يعرفه أغلب الناس بلا تفكير |
| **٤٠٠** | يحتاج شوي تركيز أو معلومة متوسطة |
| **٦٠٠** | يعرفه المهتم بالمجال فقط |

اكتب **ثلث الأسئلة بكل درجة** بالضبط.

---

## الصيغة المطلوبة (مهمة جداً)

أخرج الأسئلة **بصيغة JSON فقط**، بلا أي كلام قبلها أو بعدها، بهذا الشكل:

```json
[
  {
    "text": "نص السؤال",
    "answer": "الإجابة الصحيحة",
    "points": 200,
    "hint": "تلميح أول (اختياري)",
    "hint2": "تلميح ثانٍ (اختياري)"
  }
]
```

**الحقول:**

| الحقل | إلزامي | الشرح |
|---|---|---|
| `text` | ✅ | نص السؤال. حرفان على الأقل |
| `answer` | ✅ | الإجابة الصحيحة، مختصرة قدر الإمكان |
| `points` | ✅ | **٢٠٠ أو ٤٠٠ أو ٦٠٠ فقط** — لا شيء غيرها |
| `hint` | ❌ | تلميح يقرّب اللاعب بلا ما يعطيه الجواب |
| `hint2` | ❌ | تلميح أوضح من الأول |

لا تستخدم أي حقول ثانية.

---

## قواعد لازم تُحترم

**١. التلميح ما يكشف الجواب.**
لا تكتب الإجابة ولا أي جزء منها داخل `hint` أو `hint2` ولا داخل `text`.

- ❌ سؤال: «ما أطول أنهار العالم؟» · تلميح: «النيل يمر بمصر»
- ✅ سؤال: «ما أطول أنهار العالم؟» · تلميح: «يمر بإحدى عشرة دولة أفريقية»

**٢. الإجابة قطعية وواحدة.**
لا تكتب سؤالاً له أكثر من إجابة صحيحة، ولا سؤال رأي.

- ❌ «من أفضل لاعب في التاريخ؟»
- ✅ «من أول لاعب فاز بالكرة الذهبية خمس مرات؟»

**٣. لا تكتب معلومة تتغيّر.**
تجنّب «حالياً» و«هذا الموسم» و«أحدث». السؤال لازم يظل صحيحاً بعد سنة.

- ❌ «من هدّاف الدوري الإنجليزي حالياً؟»
- ✅ «من هدّاف الدوري الإنجليزي في موسم ٢٠٢٣-٢٠٢٤؟»

**٤. تأكد من صحة كل معلومة.** إذا مو متأكد، لا تكتب السؤال أصلاً.

**٥. لا تكرر.** ولا سؤالين يقيسان نفس المعلومة، حتى لو الصياغة مختلفة.

**٦. اختصر.** السؤال سطر واحد، والإجابة كلمة أو كلمتين إذا أمكن.

**الطلب:** «اكتب ٦ أسئلة لفئة جغرافيا»

**الجواب المتوقع:**

```json
[
  { "text": "ما أكبر محيطات العالم مساحةً؟", "answer": "المحيط الهادئ", "points": 200 },
  { "text": "في أي قارة تقع صحراء الكالاهاري؟", "answer": "أفريقيا", "points": 200,

  { "text": "ما الدولة الوحيدة التي تقع في قارتين وعاصمتها في إحداهما فقط؟", "answer": "تركيا", "points": 400,
    "hint": "تفصلها مضائق مائية" },
```

## الفئات ذات الصيغة الخاصة

هذي **لا تستخدم** الصيغة السابقة.

### 🧠 السهل الممتنع

سؤال واحد له عدة إجابات مخفية، من الأسهل إلى الأصعب، **بالإضافة إلى «فخ»**:
إجابة مشهورة جداً يقولها الناس بثقة لكنها **خارج القائمة** — فتُخصم منهم.

```json
[
  {
    "text": "اذكر أطول أنهار العالم",
    "points": 200,
    "answers": [
      { "text": "النيل",     "points": 100 },
      { "text": "الأمازون",  "points": 200 },
      { "text": "اليانغتسي", "points": 400 },
      { "text": "المسيسيبي", "points": 700 },
      { "text": "الكونغو",   "points": 1000 },
      { "text": "الدانوب",   "points": 500, "isTrap": true },
      { "text": "الفرات",    "points": 500, "isTrap": true }
    ]
  }
]
```

- الإجابات الصحيحة: من **١٠٠** (البديهية) إلى **١٠٠٠** (الأصعب)
- الفخ: `"isTrap": true` ونقاطه **٥٠٠** دائماً
- **فخّان أو ثلاثة** لكل سؤال، والفخ لازم يكون مشهوراً فعلاً — «الدانوب» فخ ممتاز، «نهر ما أحد سمع فيه» فخ فاشل
- `points` الخارجي للسؤال نفسه: ٢٠٠ أو ٤٠٠ أو ٦٠٠

### 🤫 ولا كلمة

تمثيل صامت. البطاقة موضوع، وتحتها **٦ كلمات** يمثّلها اللاعب بالإشارة بلا صوت.

```json
[
  {
    "text": "مثّل مهناً ووظائف",
    "points": 200,
    "answers": [
      { "text": "طبيب",       "points": 200 },
      { "text": "شرطي مرور",  "points": 200 },
      { "text": "حلاق",       "points": 400 },
      { "text": "قاضي",       "points": 400 },
      { "text": "طيار",       "points": 600 },
      { "text": "عالم آثار",  "points": 600 }
    ]
  }
]
```

- كل كلمة لازم **تنمثّل بالإيدين والوجه فقط** — بلا صوت ولا كلام ولا رسم
- اختر أشياء ملموسة. **تجنّب** المشاعر والمفاهيم المجردة (فرح، عدل، حرية) لأنها ما تنمثّل بوضوح
- ٦ كلمات: اثنتان ٢٠٠، اثنتان ٤٠٠، اثنتان ٦٠٠
- بلا فخوخ في هذي الفئة

### ✏️ رسم وتخمين

نفس الصيغة العادية، بس الإجابة لازم تكون **شيئاً يُرسم**: جسم أو حيوان أو مشهد بسيط.
تجنّب المجرّدات.

### 🔍 خمن الدولة

السؤال ثابت والإجابة دولة، والتلميحات **الأربعة إلزامية** ومرتّبة من الأصعب للأسهل:

```json
[
  {
    "text": "خمّن الدولة",
    "answer": "اليابان",
    "points": 400,
    "hint": "أرخبيل من أكثر من ستة آلاف جزيرة",
    "hint2": "من أكثر دول العالم عرضةً للزلازل",
    "hint3": "عاصمتها أكبر تجمّع حضري في العالم",
    "hint4": "علمها دائرة حمراء على أرضية بيضاء"
  }
]
```

⚠️ **لا يذكر التلميح اسم الدولة ولا عاصمتها ولا أي كلمة تكشفها.**
